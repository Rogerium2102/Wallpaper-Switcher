# Wallpaper Switcher

## Adding times
Click the start / end time box to bring up the enter time interface window.
## Adding wallpapers
Click the file path box to bring up the select a file button.
Please only add valid images or Windows will get upset.
An image of your chosen wallpaper will appear in the menu.
## Start at run
In order to change wallpaper on your schedule the app needs to boot at startup.
Please select the option to start at runtime. The app will do this once clicked, but is unable to remember that it was clicked between sessions so the box resets. This is a purely visual bug.
## T button
The X button closes the application entirely, if you wish for it to run in the background, click the T button instead!
